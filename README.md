# Anya's Endless Peanut Hunt

A browser-based 3D game built with React Three Fiber, featuring Anya from Spy x Family collecting peanuts around the house.

## Deploying

This is a standalone Vite + React project (no external services required).

1. Upload this folder's contents to a new GitHub repository.
2. Go to [vercel.com](https://vercel.com), sign in with GitHub.
3. Tap **Add New → Project**, select this repo.
4. Vercel auto-detects the Vite framework — no configuration needed.
5. Tap **Deploy**.

That's it — Vercel builds and hosts it, giving you a live link to play from.

## Local development

```
npm install
npm run dev
```
